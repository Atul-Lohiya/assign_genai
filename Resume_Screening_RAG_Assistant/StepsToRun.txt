1. Clone the github repo at https://github.com/Atul-Lohiya/assign_genai with command: git clone https://github.com/Atul-Lohiya/assign_genai.git
2. Install all the dependencies from requirements.txt with pip install -r requirements.txt
3. Generate sample resumes for quick testing with python generate_sample_resumes.py
4. Run streamlit with streamlit run app.py
